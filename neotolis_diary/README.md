# neotolis_diary

New devlog project scaffold.

Next steps:

1. Record voiceover with `dl serve neotolis_diary.edits.youtube`.
2. Process a take with `dl audio neotolis_diary.edits.youtube intro <take>.webm`.
3. Replace chunks in `neotolis_diary/edits/youtube/beats.py`.
4. Run `dl check neotolis_diary.edits.youtube` before rendering.
5. Render drafts with `dl render neotolis_diary.edits.youtube --width 540p --quality draft -j 6`.
