⚡ Сколько из этого реально играет (важный момент честности)

Из 30 778 строк ~22 000 действительно играют в проде. Остальные ~6 800 — это балласт от шаблона, эксперименты, legacy и pluggable platforms. Это не дыра в коде — это нормальная структура переиспользуемого шаблона.

✅ В игре (~22 000)

  • Все системы (boss, finger, collision, hand-grab)
  • Вся UI (choice modal, upgrades panel, journal, lever)
  • Весь рендер (Pixi-graphics, текстур-кеши)
  • Engine core utils (audio, save, input, layout, loc)
  • Data (balance, choices, locations, upgrade tree)
  • 1 из 4 pluggable platforms (для конкретного деплоя)

⚪ Балласт (~6 800)

  • character_world_test/ — 2 066 строк · 3D-эксперимент с персонажами, отдельная сцена
  • trailer/ — 1 015 строк · подгружается только с ?trailer=1
  • core/ резерв — ~2 200 строк · CameraController, FpsOverlay, ParticlePool, TutorialOverlay — шаблон для будущих игр
  • 4 platforms — 935 строк · нужна 1, остальные 3 спят
  • *.legacy.js — 315 строк · старые версии upgrade tree/balance
  • Возможно мёртвое — ~250 строк · LocationsPanel экспортируется, но не импортируется
Почему это важно: когда я говорю "30 тысяч строк за 13 дней" — это правда, но эффективная цифра ~22k. Шаблон core/ и платформы platform-* переедут в следующую игру. Это и есть преимущество AI-стека: пишешь шаблон один раз, переиспользуешь много раз. Test sandbox тоже останется — для следующих экспериментов с персонажами.
